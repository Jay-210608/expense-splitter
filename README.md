# Expense Splitter (DBMS Case Study)

A MySQL database that tracks shared expenses between friends and calculates who owes whom.

## Tables
- **Users**: people in the group
- **Expenses**: each expense and who paid
- **Splits**: how much each user owes per expense

## How to run
1. Run `schema.sql` to create the database and tables
2. Run `seed.sql` to load sample data
3. Run `queries.sql` to see the results

## Queries
1. Who owes whom, per expense
2. Total paid by each user
3. Total share owed by each user
4. Net balance (positive = gets money back, negative = owes money)

## Tools
MySQL, MySQL Workbench, VS Code, Git
